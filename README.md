# 邻里团购记账

给微信群团购使用的手机网页。客户自己选择商品和份数；团长发布商品、代下单、修改订单和核对收款。价格统一按分保存和计算，避免小数误差。

## 团长第一次使用

1. 打开网站的 `/admin` 页面，输入单独提供的管理密码。不要把管理密码发到群里。
2. 点「发布新一期」，把商品文案整段粘贴，点「识别商品」。逐项核对名称、规格和单价。识别不到的商品可手工添加；二选一的商品请分成两个商品。
3. 选择周一或周四晚上 10 点截单，点「核对完成，发布新一期」，然后在「订单与收款」复制客户链接发群里。

客户在链接内选份数、填微信名并提交。截单前客户可在原手机修改或取消；换手机或找不到订单时由团长代改。收到微信转账、扫码或线下付款后，团长在订单上点「核对收款」，输入实际收到的金额。改价或改订单后会重新显示待收或待退款差额。

可切换查看历史期数、按商品查看总份数，并下载 CSV 账单表格。按微信名查询应付金额是公开功能；同名客户可用订单号区分。付款状态只在管理页显示。

## 开发

运行环境为 Sites Worker、D1、Next/Vinext。`.openai/hosting.json` 声明数据库绑定；`drizzle/` 保存数据库迁移。管理密码通过 Sites 运行环境变量 `ADMIN_KEY` 设置，不放进 Git 仓库。

```text
npm ci
npm run db:generate
npm run build
```

本地预览需先在 `dist/server/.dev.vars` 设置 `ADMIN_KEY`，并按 Sites 文档将迁移应用到本地 D1，然后运行 `npm start`。
